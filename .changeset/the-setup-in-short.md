The package ships `llms.txt` beside the README: the setup in short. It gives the order of a setup per framework, the entries, the commands that verify a deployment (`pll doctor`) and that upgrade from 2.x (`pll doctor --v3`, `pll migrate`) with their exit codes, and what 3.0 no longer does. The documentation contract reads it as it reads the guides, so an entry, an option or a diagnostic code it names is one the source defines.
